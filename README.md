# e-Rapor SD

Aplikasi rapor SD Kurikulum Merdeka yang berjalan langsung di peramban. Tidak perlu instalasi, tidak perlu server, dan data tidak dikirim ke mana pun.

## Fitur

- Identitas sekolah, mata pelajaran, dan tujuan pembelajaran (TP) per kelas 1 sampai 6
- Input nilai per TP dan sumatif akhir semester, dengan nilai akhir dan deskripsi capaian terisi otomatis
- Impor dan ekspor nilai lewat Excel atau CSV, impor data peserta didik lengkap
- Ekstrakurikuler, ketidakhadiran, 7 kebiasaan anak Indonesia hebat, kokurikuler, dan catatan wali kelas
- Legger nilai kelas
- Cetak rapor dan identitas peserta didik dalam ukuran A4 atau F4, atau unduh sebagai PDF
- Cadangan dan pemulihan data dalam satu file

## Cara memakai

1. Buka halaman aplikasi di GitHub Pages repo ini.
2. Isi **Identitas Sekolah**, lalu cek **Mata Pelajaran** dan **TP**.
3. Tambahkan **Peserta Didik**, lalu isi **Input Nilai**.
4. Periksa **Legger**, lalu **Cetak Rapor**.

## Catatan penting

Data disimpan di peramban perangkat yang dipakai (localStorage). Membersihkan data peramban akan menghapusnya, jadi unduh cadangan lewat menu **Cadangkan** secara berkala.

## Menjalankan sendiri

Unduh `index.html`, lalu buka di peramban. Untuk menayangkannya di GitHub Pages: **Settings, Pages, Deploy from a branch, branch `main`, folder `/ (root)`**.
